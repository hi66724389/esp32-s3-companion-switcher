3. 系統開機與控制流程（SigmaStudio ＋ ESP32-P4）

Step 1. 畫 DSP 圖在電腦打開免費的 ADI SigmaStudio，拖拉出 32×32 Matrix Mixer、Parametric EQ、Compressor、Limiter，編譯後匯出 SigmaStudioFW C 語言標頭檔。
Step 2. 開機載入ESP32-P4 上電後，先透過 SPI (CS_DSP) 執行 ADAU1466 的 default_download()，將 DSP 程式與初始參數灌入 ADAU1466 RAM 並啟動運算。
Step 3. 即時控制使用者透過觸控螢幕、Web UI 或 PC GUI 調整推桿 / EQ 時，ESP32-P4 只需透過 SPI 寫入對應的 4-byte 記憶體位址 (Safeload Write)，完全不佔用 P4 的 CPU 音訊算力。
Step 4. 時脈同步由外部高精密 12.288MHz（或 24.576MHz）晶振接給 ADAU1466，ADAU1466 擔任全系統時脈 Master，統一輸出 MCLK / BCLK / LRCLK 給 ADC、DAC 與 ESP32-P4（I2S 設為 Slave），徹底避免不同步爆音。
