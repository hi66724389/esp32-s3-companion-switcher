八、Linux ASoC 驅動架構、SAI 介面與多晶片設備樹 (DTS) 實作詳解

釐清核心驅動 (.c)、匯流排掛載與設備樹 (.dts) 的分工，並附上雙顆 CS42448 實戰範本與樹莓派同架構參考資源。

1. 檔案層級分工與 SAI 說明

  • <chip>.c（如 cs42xx8.c）：音訊與 TDM 核心邏輯（並非設備樹），定義通道數、取樣率、I2S/TDM 格式與 ALSA 混音暫存器。
  • <chip>-i2c.c / -spi.c：控制匯流排掛載介面（硬體二選一即可），僅傳送音量與模式設定指令；高速音訊永遠走 SoC 的 SAI / I2S (TDM) 腳位。
  • SAI（Serial Audio Interface，串列音訊介面）：SoC 內部負責處理 I2S / TDM 高速數位音訊的硬體控制器，負責發送與接收 MCLK、BCLK、FSYNC 與串列音訊資料。
  • 設備樹（.dts → .dtb/.dtbo）：硬體接線說明書。多顆相同晶片無法自動偵測，須設不同 I2C 位址（如 0x48、0x49）並分別綁定至 &sai0 / &sai1。

2. 雙顆 CS42448 設備樹 (.dts) 範例

/ {
    sound {
        compatible = "simple-audio-card";
        simple-audio-card,name = "luckfox-multi-cs42448";

        simple-audio-card,dai-link@0 {
            format = "dsp_a";
            bitclock-master = <&link0_cpu>;
            frame-master = <&link0_cpu>;
            mclk-fs = <256>;
            link0_cpu: cpu { sound-dai = <&sai0>; dai-tdm-slot-num = <8>; dai-tdm-slot-width = <32>; };
            codec { sound-dai = <&cs42448_a>; };
        };

        simple-audio-card,dai-link@1 {
            format = "dsp_a";
            bitclock-master = <&link1_cpu>;
            frame-master = <&link1_cpu>;
            mclk-fs = <256>;
            link1_cpu: cpu { sound-dai = <&sai1>; dai-tdm-slot-num = <8>; dai-tdm-slot-width = <32>; };
            codec { sound-dai = <&cs42448_b>; };
        };
    };
};

&i2c1 {
    status = "okay";
    cs42448_a: cs42448@48 { compatible = "cirrus,cs42448"; reg = <0x48>; #sound-dai-cells = <0>; clocks = <&audio_mclk>; clock-names = "mclk"; status = "okay"; };
    cs42448_b: cs42448@49 { compatible = "cirrus,cs42448"; reg = <0x49>; #sound-dai-cells = <0>; clocks = <&audio_mclk>; clock-names = "mclk"; status = "okay"; };
};

&sai1 { #sound-dai-cells = <0>; status = "okay"; };
