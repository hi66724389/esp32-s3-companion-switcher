★ 兩大廣電級核心音訊設計（寫入韌體初始化流程）：
1. 【🎧 0.0 ms 零延遲即時聽自己 (Hardware Analog Sidetone)】：開啟 WM8960 暫存器 R47 (Left Output Mixer) 與 R48 (Right Output Mixer) 的 LI2LO / RI2RO 位元，讓本機麥克風經過 PGA 放大後，直接在晶片內部類比混入耳機 HP_L / HP_R（延遲 = 0.0 ms，無數位回音）；當撥桿切回中間 MUTE 時同步關閉該位元。
2. 【🔊 面板內建 8Ω/1W 小喇叭 + 發話自動消音防嘯叫 (Auto Speaker Cut)】：小喇叭接 WM8960 SPK_LP / SPK_LN。一來類比自聽絕不送進小喇叭；二來只要壓下發話撥桿 (PTT / Latch) 打開麥克風，韌體立刻將 R40/R41 SPKVOL 設為靜音 (或 -20dB Dim)，放開撥桿瞬間恢復，徹底防止面板小喇叭與麥克風產生刺耳回授嘯叫！
